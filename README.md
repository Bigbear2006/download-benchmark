# download_bench — замер скорости скачивания
 
Небольшой скрипт на Python + aiohttp. Делает 10 запросов к указанному адресу
**строго последовательно**, на каждый дожидается полного тела ответа и выводит
статистику: среднее время запроса, общий объём и скорость скачивания.

## Требования
 
- Python 3.9+
- aiohttp (см. `requirements.txt`)
## Установка
 
```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Запуск
 
```bash
python main.py <URL>
```
 
Пример:
 
```bash
python main.py https://example.com/big-image.jpg
```
 
Необязательный параметр `-n` меняет число запросов (по умолчанию 10):
 
```bash
python main.py https://example.com/big-image.jpg -n 5
```
 
## Пример вывода
 
```
URL: https://example.com/big-image.jpg
Запросов: 10 (последовательно)
 
[ 1/10]    8.40 МБ за   1.052 с (   7.98 МБ/с)
[ 2/10 ]    8.40 МБ за   0.987 с (   8.51 МБ/с)
...
 
Успешных запросов:    10 из 10
Среднее время запроса: 1.004 с
Скачано всего:         84.00 МБ
Скорость скачивания:   8.37 МБ/с
```
 
## Единицы измерения
 
| Величина                | Единица                                 |
|-------------------------|-----------------------------------------|
| Время                   | секунды (с)                             |
| Объём данных            | мегабайты (МБ), 1 МБ = 1 000 000 байт   |
| Скорость скачивания     | **мегабайты в секунду (МБ/с)**          |
 
Чтобы перевести в мегабиты в секунду (как обычно указывают тарифы
провайдеров), умножьте МБ/с на 8.
 
## Как считаются значения
 
- **Время запроса** — от отправки запроса до получения последнего байта тела
  ответа (без учёта записи на диск: данные в файл не сохраняются, только
  подсчитывается их размер).
- **Среднее время** — сумма времён успешных запросов / их количество.
- **Общий объём** — сумма размеров тел ответов всех успешных запросов.
- **Скорость** — общий объём / суммарное время успешных запросов. Это
  средняя скорость за весь замер, а не среднее арифметическое скоростей
  отдельных запросов.

## Особенности
 
- Запросы выполняются в одной `ClientSession`, поэтому соединение может
  переиспользоваться (keep-alive). Первый запрос обычно чуть медленнее из-за
  установки соединения и TLS-рукопожатия.
- Скрипт отправляет `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и
  объём соответствовал реально переданным данным.
- Ошибки (сеть, таймаут, код ответа 4xx/5xx) не прерывают работу: запрос
  помечается неудачным и не учитывается в статистике. Если не удался ни один
  запрос, скрипт завершается с кодом 1.
- Таймауты: 10 с на установку соединения и 30 с без получения данных. Общего
  лимита на скачивание нет, чтобы не обрывать тяжёлые файлы.
- Скорость зависит от канала, сервера и кеширования на стороне CDN, поэтому
  результаты разных запусков могут отличаться.
